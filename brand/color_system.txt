# BINLY — COLOR SYSTEM (WHITE MODE + elegant glow — owner decision 2026-10-20; overrides the cream/paper notes below)
# Background = clean white #FFFFFF (never cream). Key accent = gold #B07D0C with a soft gold glow. Labels = glowing
# rounded pills. Hero objects get a soft halo + a few sparkles. Dark only for naturally dark scenes. Elegant, never neon.


## Creative direction
A warm, paper-toned palette inspired by old scientific print and archival documents — not a dark/night/space palette. The feel is "a well-preserved old scientific journal or medical document," not "cartoon nighttime adventure."

## Core palette (CURRENT — the old cream/paper table below this line was retired 2026-10-20)
| Role | Hex |
|---|---|
| Background | #FFFFFF clean white |
| Text | #2B2420 ink, bold |
| Key accent | #B07D0C gold (glows) |
| Signal / warning | #8B2E1F oxblood |
| Semantic | evidence #2F5233 · theory #5C4A72 · caution #B8860B |
See docs/PLAYBOOK.md "THE LOOK" and src/kit/theme.ts for the full palette.
