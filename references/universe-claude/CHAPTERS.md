# CHAPTERS — the model video's chapters, by KIND (for matching a new script)

Every AZTIKA script is a different idea in the same niche, but its chapters are the same KINDS of story the model video
tells. Before planning, the director matches each chapter of the new script to the reference chapter of the same kind
(not the same topic) and plans its shots the way that chapter was built — then studies only that time range closely.
Times = the model video (14:47). Sheet = `references/universe-claude/shots/shots-NN.jpg` (every shot, numbered).
Board = the home stage returns (podium) at 1:34 · 2:30 · 4:04 · 5:41 · 6:22 · 6:31 · 7:42 · 9:33 · 12:16 · 14:00.
